# Crash coordinate corrections

## Bolin and Reynolds

The same compilation lists Bolin 1.8 km southeast of Krauthausen (page 1), and Reynolds 2.5 km east of Polch (page 2). Replace generic Eisenach/Koblenz markers with approximate offsets, not purported surveyed wreck points. Modern town reference coordinates checked October 1, 2026: Krauthausen 51.017222 N, 10.270000 E (https://de.wikipedia.org/wiki/Krauthausen); Polch 50.301111 N, 7.316667 E (https://de.wikipedia.org/wiki/Polch). Spherical offsets at bearings 135/90 degrees respectively give Bolin 51.0058 N, 10.2882 E and Reynolds 50.3011 N, 7.3519 E. Same reference-point/datum/bearing uncertainty applies as for Hautman. These corrections do not prove individual aircraft headings or loss times.

## Hautman

The Hassenpflug compilation, `Maps/Germany/Crash Sites/Germans list of crash locations by plane001.pdf`, page 1, lists 2.5 km southeast of Bassenheim; handwritten clarification says 11 km west of Koblenz. The former runtime coordinate 7.60 E, 50.05 N and label “137 mi SW” did not implement this location.

Bassenheim's modern reference coordinate is 50°21′35″ N, 7°27′42″ E: https://www.wikidata.org/wiki/Q566930 (checked October 1, 2026). Applying a spherical 2,500-metre offset at bearing 135 degrees gives approximately 7.4866 E, 50.3438 N. This is only an approximate area marker: the source does not specify the town reference point, precise bearing, datum, error bounds or surveyed wreck coordinates. Runtime metadata and label explicitly preserve that limitation. No inference about Hautman's airborne track follows from this change.
